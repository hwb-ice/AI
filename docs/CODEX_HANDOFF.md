# Codex 实施任务：Windows 11 AI 项目与 Skill 管理中枢

用户已经同意把本地 AI 项目统一规划到 `D:\GPT`，所有 Skill 源码统一由 **私有** GitHub `hwb-ice/AI` 管理。不要把本地工作文件全部上传远端。

## 六个必须建设的能力
1. **项目总控台**：自动生成/维护项目索引，界面显示名称、位置、类型、Git 仓库、运行状态、最后更新、风险、任务和本地打开路径；数据可导出 JSON/Excel。支持新增、扫描、查重、搜索和按类别筛选。
2. **Skill 自动发现与调度**：当前环境真实安装清单、GitHub 技能目录和项目匹配表分离；每项新专业任务自动选择 1～3 个互补技能；无合适工具再搜索可信仓库，评估许可证、依赖、脚本风险。新增合适 Skill 时默认入 `hwb-ice/AI` 仓库管理，**无需反复问存哪里**，但不自动运行风险脚本；后台自动检测更新可实现，升级仅经测试/批准后执行。
3. **备份与恢复**：首次移动前本地备份/恢复测试，版本化项目代码与配置；敏感文件按范围加密或仅留本地；重要项目建立可恢复点。验收包含一次实际恢复演练。
4. **Codex/Work/ChatGPT 环境桥接**：GitHub 是代码索引与来源、`D:\GPT` 是 Windows 工作区。Codex 以 `AGENTS.md` 和项目级 `.agents/skills` 自动发现；Work/ChatGPT 仅通过各自实际支持的连接器、插件或项目指令加载。输出兼容矩阵 `可读取/已安装/可执行/已验证`；不能假定共享。
5. **自动化测试**：每个项目建立轻量、可重复的 smoke test / regression test；失败时保留原版并生成日志。重点覆盖题库正确答案和出处、CAD 面积与 Xrefs、沥青面积密度吨位、视频输出字幕/格式、部署同步。
6. **权限与隐私**：默认仅本地存储项目文档、公司资料、PDF 原件、CAD 图纸、视频原素材、个人数据；只有明确允许的代码/规则/开源 Skill 才进 GitHub。过滤 `.env`、token 和密钥；标注本地/私有 GitHub/允许共享的资料级别。

## Phase 0：只读清点（**现在只执行这个阶段**）
- 确认 Windows 用户目录及磁盘空间；重点扫描用户桌面、文档、下载、常见代码目录和 D 盘其他项目；遵守访问权限，避免遍历 OS/系统缓存文件。
- 检测项目根目录、代码、CAD 图纸、外部参照、PDF、题库、Excel、AI 视频素材、模型、脚本、Git 仓库和已有安装的 Skill。
- 使用文件大小、内容哈希及结构判重；不同版本不擅自合并。
- 为每个项目记录：原路径、建议 `D:\GPT` 下目录、文件数/大小、最后修改时间、技术栈、Git 状态、外部路径、部署依赖、敏感级别、风险、是否正在使用。
- 生成 `D:\GPT\00_项目总览\项目总清单.xlsx`、`迁移计划.xlsx`、`README.md`，若目标目录不存在可安全创建空目录，但**不要搬动/删除/覆盖原项目**。
- 标记潜在 Windows 符号链接、虚拟环境、数据库路径、Supabase/Vercel 配置、CAD 外部参照可能被迁移破坏的地方。
- 展示扫描汇总、建议分类、备份空间需求、冲突与应人工确认的问题，并**暂停**。

## Phase 1：审核通过后才做备份和样本迁移
- 根据清单让用户明确选择需迁移的项目；检查磁盘容量，备份到独立位置，验证可读与校验和。
- 选一个**不涉及生产数据的测试项目**，复制而不是直接移动；保持原始目录结构，修复可控路径并运行 Smoke Test。
- 对比文件计数、大小/哈希、运行配置。先提交详细结果再等待用户是否扩大迁移范围。
- 未确认前不得删除旧路径、修改全局 Git/Codex 配置或更改线上环境。

## Phase 2：逐项目迁移及总控台 MVP
- 小批量复制－验证－交付－批准后清理，任何失败可回滚。
- 目录建议：`00_项目总览/01_道路工程/02_AI软件开发/03_AI视频工厂/04_投资分析系统/05_AI工具仓库/06_学习与资料/98_待分类/99_历史归档`。已有项目优先保持根结构而非拆分程序。
- 总控台首版优先本地 Web UI 或 Python GUI，不引入复杂服务器；提供目录索引、搜索、扫描、版本状态、错误报告及备份恢复入口。
- 后续加自动化安全更新与项目健康检查，运行结果必须展示测试证据。
